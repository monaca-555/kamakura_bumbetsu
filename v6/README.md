# 鎌倉ごみ分別さがし

鎌倉市が配布している「資源物とごみの品目と分別区分（50音順索引）」冊子（p.42〜65）を元にした、
品名から分別区分を検索できる非公式のシンプルな静的Webアプリです。

## 使い方

ビルド不要の素の HTML/CSS/JS です。ブラウザで `index.html` を開くか、静的サーバーで配信してください。

```sh
python3 -m http.server 8000
# http://localhost:8000/ にアクセス
```

GitHub Pages でそのまま公開できます（`index.html` がルート）。

## 構成

- `index.html` — ページ本体
- `css/style.css` — スタイル（ライト/ダーク自動対応）
- `js/app.js` — 検索・絞り込み・詳細表示ロジック
- `data/items.js` — 品目データ（品名・分別区分・出し方のポイント・冊子の関連ページ）

## データについて

`data/items.js` は鎌倉市配布冊子の50音順索引（あ〜わ、約1000行・変則材質違いを含む）を書き起こしたものです。
表記の誤りに気づいた場合は `data/items.js` を直接修正してください。
最新・正確な情報は必ず鎌倉市公式サイトでご確認ください。
